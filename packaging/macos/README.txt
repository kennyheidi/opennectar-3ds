Open Nectar - Pikmin 1 and Pikmin 2 for macOS
=============================================

1. Extract nectar-macos.tar.gz anywhere.
2. macOS blocks programs downloaded from the internet that are not from the
   App Store. Open Terminal in the extracted folder and run once:

       xattr -dr com.apple.quarantine .

   (Or right-click nectar-launcher > Open, and confirm.)
3. Open nectar-launcher. It asks for your disc image (ISO, GCM, RVZ...) and
   an install folder, and leaves a shortcut "Open Nectar" on the Desktop.

From then on use the launcher in the install folder (or the Desktop
shortcut): it plays, sets up and updates both games. If you open this
downloaded launcher again, it sends you to the installed one.

Supported discs: Pikmin USA (GPIE01) and Europe (GPIP01), Pikmin 2 USA
(GPVE01) and Europe (GPVP01). Bring your own disc image.
